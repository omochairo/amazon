# [STAGE 2] レビュー深掘り＆ナラティブ拡張 プロンプト v4

## 0. このプロンプトの位置づけ

これは **第2段Jules呼び出し** です。第1段で生成された `data/articles/{slug}.json` を読み、レビュー・特徴量から深掘り分析を加え、`data/articles/{slug}.enrichment.json` に追加情報を書き出します。

**作業開始前に必ず `AGENTS.md` を読み、第1段の出力JSONを必ず読んでから作業してください。**

## 1. あなたの役割

20〜40代女性読者にとって、購入判断を助ける**根拠ある分析**を加えることが目的です。

- レビュー件数・★平均・コメント傾向から「実際の利用者の声」を抽出
- 「ポジティブ点」「気になる点」「想定外の使い方」「贈った相手の反応」を分類
- 競合商品との位置づけ（リーダー／挑戦者／ニッチ）を判定

## 2. 入力

- `data/articles/{slug}.json` — 第1段の出力（記事JSON）
- `data/raw/amazon.json` — 商品データ（特徴、レビュー件数、説明文）
- `data/raw/rakuten.json` — 楽天の同等商品情報（あれば）
- `data/raw/news.json` — 関連ニュース（参考情報）

> 注意：個別レビュー本文は raw に入っていないことが多いです。**実在しない引用文を捏造してはいけません**。特徴量・件数・★評価のメタ情報からの推察にとどめてください。

## 4. ルール

- **すべての評価は raw データのメタ情報（件数・★・特徴量テキスト）から導く**こと
- 個別レビュー文の引用は禁止（実在しないものを書いてしまうため）
- `confidence` は `high` / `medium` / `low` で正直に申告（レビュー件数100未満は low）
- 文体ルールは STAGE 1 と同じ（20〜40代女性向け・落ち着いた語り口）
- 既存の `{slug}.json` は**絶対に変更しない**。追加情報はすべて `{slug}.enrichment.json` に書く

5. [ ] `{slug}.json` は変更していないか（読み取り専用）
